O HTML (HyperText Markup Language ou Linguagem de Marcação de Hipertexto) é a espinha dorsal de toda a internet.

O que ele não é: HTML não é uma linguagem de programação. Ele não possui lógica, não toma decisões (não tem if/else), não faz laços de repetição (não tem for/while) e não guarda variáveis.

O que ele é: Ele é estritamente uma Linguagem de Marcação. Sua única função é "marcar" (anotar) um documento de texto simples para dizer ao navegador o que cada parte daquele texto significa. Ele avisa o Chrome, Edge ou Safari: "Isto é um título", "Isto é um parágrafo", "Isto é uma imagem".

Contexto Histórico: Foi inventado em 1991 por Tim Berners-Lee no CERN (Organização Europeia para a Pesquisa Nuclear). O problema da época era que cientistas de diferentes universidades não conseguiam compartilhar documentos de forma fácil. O HTML nasceu para ser uma linguagem universal de documentos, interligados através de "Hipertextos" (os famosos links), permitindo pular de um documento para outro instantaneamente.

Hoje, na sua versão HTML5, ele evoluiu de um simples formatador de textos para uma plataforma capaz de rodar aplicações complexas, suportando áudio, vídeo, gráficos 2D/3D e integrações nativas com APIs do navegador.

Quando o navegador lê o seu arquivo HTML, ele o transforma em uma árvore de elementos estruturada chamada DOM (Document Object Model). Para que o navegador construa essa árvore corretamente, seu arquivo precisa de um "esqueleto" fundamental.

Abra seu editor e analise a anatomia de um documento HTML padrão:

<!-- 1. A DECLARAÇÃO DOCTYPE -->
<!DOCTYPE html>

<!-- 2. O ELEMENTO RAIZ -->
<html lang="pt-BR">

  <!-- 3. A CABEÇA (HEAD) -->
  <head>
    <title>Painel Tático Central</title>
  </head>

  <!-- 4. O CORPO (BODY) -->
  <body>
    <h1>Bem-vindo ao Sistema</h1>
    <p>Todos os módulos operantes.</p>
  </body>

</html>

Dissecando cada linha:

  1. <!DOCTYPE html>: No passado, existiam dezenas de versões confusas de HTML. Essa linha foi criada para ativar o "Modo Padrão" (Standards Mode) do navegador. Ao digitar exatamente isso, você garante que o navegador vai renderizar a página usando as regras mais modernas do HTML5, evitando que o site quebre em navegadores mais novos.
  2. <html lang="pt-BR">: É a raiz da árvore do DOM. O atributo lang é vital. Ele avisa aos motores de busca (Google) e aos leitores de tela para deficientes visuais que o conteúdo está em Português do Brasil. Sem isso, um leitor de tela tentaria ler seu site em português com sotaque americano.
  3. <head>: É o centro de inteligência da página. Tudo o que vai aqui dentro é invisível para o usuário final (exceto a tag de título, que aparece na aba do navegador). Aqui carregamos fontes, arquivos CSS, scripts, e meta-dados.
  4. <body>: É a área de renderização visual. Absolutamente tudo o que você quer que o usuário veja, clique ou interaja precisa estar encapsulado dentro desta tag.

As tags <meta> ficam obrigatoriamente dentro do <head>. O papel delas é fornecer metadados (dados sobre os dados), configurando o comportamento interno do navegador e passando informações para os robôs do Google (crawlers).

As duas mais importantes, que nunca podem faltar no seu projeto, são:

<head>
  <!-- 1. Configuração de Tabela de Caracteres -->
  <meta charset="UTF-8">

  <!-- 2. Configuração de Responsividade (Viewport) -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  
  <title>Documentação Oficial</title>
</head>

Por que elas são obrigatórias?

  • charset="UTF-8": Sem esta tag, o navegador tenta adivinhar a codificação do seu arquivo. Se ele adivinhar errado, todos os caracteres especiais do português (ç, á, ã, é) vão se transformar em símbolos quebrados na tela (ex: AÃ§Ã£o). O UTF-8 é o padrão universal que engloba quase todos os caracteres de todos os idiomas do mundo.
  • name="viewport": Historicamente, os celulares reduziam o tamanho dos sites de computador para caber na telinha (gerando um mini-site onde você precisava dar zoom com os dedos). Essa tag proíbe esse comportamento. Ela diz ao celular: "A largura do site (width) deve ser exatamente igual à largura física da tela do aparelho (device-width), e o zoom inicial (initial-scale) deve ser 1.0 (100%)". Isso é o que permite o CSS Responsivo funcionar.

Até a chegada do HTML5, os desenvolvedores construíam o layout inteiro usando apenas <div> (uma caixa genérica sem significado lógico). O código virava uma "sopa de divs", ilegível para humanos e máquinas.

O HTML5 introduziu a Semântica: tags que têm nomes que descrevem exatamente a finalidade do conteúdo que carregam.

Os 3 Grandes Pilares da Semântica:

  1. Acessibilidade (A11y): Usuários cegos navegam usando o teclado (pressionando a tecla Tab). O software de leitura de tela usa as tags semânticas para anunciar: "Você entrou no rodapé", ou "Pular para o conteúdo principal".
  2. SEO (Search Engine Optimization): O robô do Google não "enxerga" o visual do seu site. Ele lê o código. Se o seu artigo principal estiver dentro de um <article>, o Google entende que aquilo é a informação de maior relevância e melhora sua posição nas buscas.
  3. Manutenibilidade: Para outro programador que herdar seu código, é muito mais fácil entender a arquitetura visual lendo tags bem nomeadas.

Dicionário de Tags Semânticas Estruturais:

  • <header>: Representa o cabeçalho introdutório. Geralmente abriga a logo da empresa e o menu principal. Pode ser usado mais de uma vez (ex: o cabeçalho de um artigo).
  • <nav>: Vem de Navigation. Deve encapsular os links principais de navegação do site. (Não use para todo e qualquer link, apenas para menus importantes).
  • <main>: O conteúdo central e dominante da página. Regra de ouro: Só pode existir um único <main> por página.
  • <section>: Agrupa um bloco temático de conteúdo. Imagine como os capítulos de um livro. Toda <section> geralmente deve começar com um título (<h2> ou <h3>).
  • <article>: Um bloco de conteúdo autossuficiente. Se você arrancar esse bloco e colar em outro site, ele ainda fará sentido (ex: uma notícia de blog, um card de produto em um e-commerce).
  • <footer>: O rodapé da página ou da seção. Costuma guardar links úteis, CNPJ, direitos autorais e contatos.

As tags sozinhas às vezes não têm informações suficientes para funcionar. É aí que entram os Atributos.

Eles são informações adicionais injetadas sempre na tag de abertura, seguindo o formato de par chave-valor: nome-do-atributo="valor".

Tipos de Atributos:

  1. Atributos Globais: Podem ser aplicados em literalmente qualquer tag HTML.
    • id: É o CPF do elemento. Dá um nome único na página. Muito usado para o JavaScript encontrar elementos específicos.
    • class: É o uniforme. Serve para agrupar vários elementos sob o mesmo nome para estilizá-los em massa com o CSS.
    • style: Permite injetar regras visuais de CSS diretamente na linha do HTML.
  2. Atributos Específicos: Só funcionam em tags que precisam deles.
    • src (Source/Fonte): Usado na tag <img> para informar de onde o navegador deve baixar o arquivo da imagem.
    • href (Hypertext Reference): Usado na tag de âncora <a> para dizer qual é a URL de destino quando o usuário clicar no link.
    • target="_blank": Usado em links para forçar a abertura em uma nova aba, impedindo que o usuário saia do seu site.

O caso crucial do atributo ‘alt' (Texto Alternativo): Toda imagem (<img>) exige o atributo alt. Ele tem dupla função: se a internet falhar e a imagem não carregar, esse texto aparece no lugar. E, mais importante, é esse o texto que o leitor de tela lê para um usuário cego saber o que a imagem representa.

<!-- Exemplo Completo de Atributos -->
<img 
  id="logo-principal" 
  class="img-redonda sombra-suave" 
  src="logo.png" 
  alt="Logotipo oficial da corporação" 
  style="margin-top: 10px;"
>

Missão: Você foi escalado para construir uma "Ficha de Status de Operação" para uso interno da corporação. Seu objetivo é utilizar a estrutura raiz correta, tags semânticas lógicas e aplicar estilos utilizando o esquema de cores Verde Oliva / Militar.

Instruções:

  1. Crie um arquivo chamado index.html.
  2. Digite a estrutura completa, analisando os comentários do código abaixo para fixar onde aplicar as áreas corretas do layout.
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dossiê de Operador - Sistema Tático</title>
</head>

<!-- O 'body' recebe o estilo global de cores: fundo verde militar muito escuro e letras verdes claras -->
<body style="background-color: #1a1e15; color: #a3c489; font-family: 'Courier New', Courier, monospace; padding: 20px;">

  <!-- CABEÇALHO DA PÁGINA -->
  <header style="border-bottom: 2px solid #4B5320; padding-bottom: 15px;">
    <h1 style="color: #d1e2c4;">Dossiê Operacional Ativo</h1>
    
    <!-- Navegação Semântica -->
    <nav>
      <a href="#" style="color: #a3c489; margin-right: 15px;">[ Módulo Inicial ]</a>
      <a href="#" style="color: #a3c489;">[ Relatórios ]</a>
    </nav>
  </header>

  <!-- CONTEÚDO CENTRAL E DOMINANTE -->
  <main style="margin-top: 25px;">
    
    <!-- PRIMEIRA SEÇÃO: Identificação -->
    <section style="background-color: #2c3325; padding: 20px; border-radius: 4px; border: 1px solid #4B5320; margin-bottom: 20px;">
      <h2 style="color: #d1e2c4; margin-top: 0;">Identificação do Alvo</h2>
      
      <!-- Atributos vitais da imagem: src e alt -->
      <img src="https://images.unsplash.com/photo-1506869640319-fea1a2753c53?w=150&auto=format&fit=crop&q=80" 
           alt="Foto de perfil de um soldado camuflado" 
           style="border-radius: 5px; border: 3px solid #4B5320;">
      
      <p><strong>Codinome:</strong> Espectro</p>
      <p><strong>Status:</strong> Em missão</p>
    </section>

    <!-- SEGUNDA SEÇÃO: Lista de Habilidades -->
    <section style="background-color: #2c3325; padding: 20px; border-radius: 4px; border: 1px solid #4B5320;">
      <h2 style="color: #d1e2c4; margin-top: 0;">Competências Técnicas</h2>
      
      <!-- Lista não ordenada (Unordered List) -->
      <ul style="list-style-type: square;">
        <li>Estruturação Semântica (HTML5)</li>
        <li>Estilização Tática (CSS3)</li>
        <li>Lógica de Engajamento (JavaScript)</li>
      </ul>
    </section>

  </main>

  <!-- RODAPÉ DA PÁGINA -->
  <footer style="margin-top: 40px; font-size: 0.85em; color: #5a7343; border-top: 1px dashed #4B5320; padding-top: 15px;">
    <p>Documento de uso restrito. Acesso registrado no servidor. © 2026 Forças de Desenvolvimento.</p>
  </footer>

</body>
</html>
