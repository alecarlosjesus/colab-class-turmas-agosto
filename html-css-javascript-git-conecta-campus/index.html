Neste Codelab, você transformará os wireframes do Conecta Campus v0.2 em um site real, navegável e responsivo.

As tecnologias trabalhadas serão:

  • HTML5
  • CSS
  • JavaScript
  • Git
  • GitHub

Não crie outro repositório

Este trabalho continua no mesmo repositório conecta-campus usado nos Codelabs anteriores. A continuidade do histórico faz parte do projeto.

Você partirá do marco v0.2, que possui:

  • repositório local e remoto;
  • branch principal main;
  • arquivo docs/wireframe.md;
  • wireframes das telas Home, Locais e Detalhes;
  • Pull Request do marco anterior já integrado.

Um navegador não recebe uma imagem pronta da página. Ele:

  1. lê o HTML;
  2. identifica os recursos externos;
  3. carrega CSS, JavaScript e imagens;
  4. constrói representações em memória;
  5. calcula tamanhos e posições;
  6. desenha o resultado na tela;
  7. reage às interações do usuário.

Escolher a tecnologia correta

Exemplos:

  • texto alternativo pertence ao HTML, porque comunica o conteúdo;
  • cor do cabeçalho pertence ao CSS, porque controla apresentação;
  • reação ao clique pertence ao JavaScript, porque representa comportamento;
  • mensagem de commit pertence ao Git, porque explica o histórico.

A página deve continuar compreensível sem CSS. JavaScript não deve substituir um link simples por uma interação desnecessária.

O branch do site deve nascer da versão mais recente e integrada do projeto.

Abrir a pasta correta

No terminal, entre no repositório:

cd caminho/para/conecta-campus

Confira o local:

pwd

O final do caminho deve indicar conecta-campus.

Atualizar a main

Execute um comando por vez:

git switch main
git pull
git status

Entenda os comandos:

  • git switch main: muda para o branch principal;
  • git pull: recebe e integra alterações do remoto acompanhado;
  • git status: mostra branch, alterações e estado de sincronização.

Critério para continuar

  • [ ] O branch atual é main.
  • [ ] O pull terminou sem conflito.
  • [ ] git status mostra working tree clean.

Se git status mostrar alterações, pare. Descubra a origem dos arquivos antes de continuar. Não use descarte forçado para esconder trabalho desconhecido.

Criar o branch do site

git switch -c feature/site-inicial
git branch --show-current
git status

Entenda:

  • switch: troca de branch;
  • -c: cria um novo branch;
  • feature/site-inicial: descreve uma evolução funcional;
  • os arquivos HTML, CSS, JavaScript e imagens pertencem ao mesmo conjunto funcional.

O resultado esperado é:

feature/site-inicial

Como ler um caminho relativo

Um caminho relativo parte do arquivo que está sendo lido.

css/style.css

significa:

  1. entre na pasta css;
  2. carregue o arquivo style.css.

Partindo de index.html:

significa:

  1. entre na pasta img;
  2. carregue biblioteca-campus.png.

Caminho relativo e caminho iniciado por barra

<link rel="stylesheet" href="css/style.css" />

O caminho acima parte do documento HTML.

Já:

<link rel="stylesheet" href="/css/style.css" />

parte da raiz do site servido. Essa raiz pode não coincidir com a pasta do projeto quando a página é aberta localmente ou publicada em um subcaminho.

Imagem com HTML acessível

<img
  src="img/biblioteca-campus.png"
  alt="Interior da biblioteca com estantes, mesas de estudo e corredor central"
  width="1536"
  height="1024"
/>

Entenda cada atributo:

  • src: caminho do arquivo;
  • alt: descrição relevante para o contexto;
  • width: largura intrínseca da imagem;
  • height: altura intrínseca;
  • as dimensões ajudam o navegador a reservar espaço antes do carregamento.

Como escrever um bom alt

Um bom texto alternativo:

  • descreve o conteúdo necessário;
  • considera o contexto em que a imagem aparece;
  • não repete o nome do arquivo;
  • não começa obrigatoriamente com "imagem de";
  • não inclui informações inexistentes.

Exemplo ruim:

<img src="img/biblioteca-campus.png" alt="imagem" />

Exemplo melhor:

<img
  src="img/biblioteca-campus.png"
  alt="Interior da biblioteca com estantes, mesas de estudo e corredor central"
/>

Se uma imagem fosse puramente decorativa, alt="" poderia ser adequado. Neste projeto, as imagens identificam os locais e precisam de descrição.

HTML é uma linguagem de marcação. Ele descreve a estrutura e o significado do conteúdo.

Elemento, tag e atributo

Observe:

<a href="locais.html">Explorar locais</a>
  • é a tag de abertura;
  • href="locais.html" é um atributo;
  • Explorar locais é o conteúdo;
  • é a tag de fechamento;
  • o conjunto forma um elemento.

Documento base

Cada página começará com esta estrutura:

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Conecta Campus | Início</title>
    <link rel="stylesheet" href="css/style.css" />
    <script src="js/script.js" defer></script>
  </head>
  <body>
    <!-- O conteúdo visível será escrito aqui. -->
  </body>
</html>

Explicação linha por linha

DOCTYPE

<!DOCTYPE html>

Informa ao navegador que o documento utiliza o modo moderno do HTML.

Idioma

<html lang="pt-BR">

Informa que o conteúdo principal está em português do Brasil. Leitores de tela podem usar essa informação para escolher a pronúncia.

Codificação

<meta charset="UTF-8" />

Permite representar acentos e uma grande variedade de caracteres.

Viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0" />

Orienta o navegador móvel a considerar a largura real do dispositivo.

Título

<title>Conecta Campus | Início</title>

Nomeia a aba e ajuda o usuário a identificar a página.

Cada página terá um título diferente:

Conecta Campus | Início
Conecta Campus | Locais
Conecta Campus | Biblioteca Central

CSS externo

<link rel="stylesheet" href="css/style.css" />

Conecta o mesmo arquivo CSS às três páginas.

JavaScript externo

<script src="js/script.js" defer></script>

defer faz o navegador analisar o HTML antes de executar o script.

Regras do projeto

  • Não use CSS em style="".
  • Não use JavaScript em onclick="".
  • Não coloque
  • Use
  • somente dentro de listas.
  • Use arquivos externos compartilhados.

Cabeçalho da Home

Dentro do de index.html, substitua o comentário por:

<header class="cabecalho">
  <div class="container cabecalho-conteudo">
    <a
      class="marca"
      href="index.html"
      aria-label="Conecta Campus - página inicial"
    >
      Conecta Campus
    </a>

    <nav aria-label="Navegação principal">
      <ul class="menu">
        <li><a aria-current="page" href="index.html">Início</a></li>
        <li><a href="locais.html">Locais</a></li>
        <li><a href="detalhes.html">Acessibilidade</a></li>
      </ul>
    </nav>
  </div>
</header>

<main id="inicio">
  <!-- O conteúdo principal será criado nas próximas etapas. -->
</main>

<footer class="rodape">
  <div class="container">
    <p>
      Conecta Campus · versão 0.3 ·
      <span data-ano-atual>2026</span>
    </p>
  </div>
</footer>

Entendendo a navegação

  • a marca é um link para a página inicial;
  • nav recebe um nome por aria-label;
  • os links formam uma lista real;
  • aria-current="page" identifica o link da página atual;
  • main guarda o conteúdo principal;
  • o rodapé possui um ano inicial mesmo sem JavaScript.

Ajustar nas outras páginas

Em locais.html, somente o link Locais recebe:

aria-current="page"

Em detalhes.html, somente Acessibilidade recebe o atributo.

Regra importante

Use:

  • para levar a outro endereço;

Não faça:

<a href="locais.html"><button>Locais</button></a>

Elementos interativos aninhados produzem comportamento e foco confusos.

Por que usar article?

Cada cartão representa uma unidade compreensível: possui imagem, categoria, título, resumo e destino.

Class e id

Use class quando o estilo pode ser reutilizado:

Use id quando o identificador precisa ser único:

<h2 id="titulo-destaques">

Não duplique IDs entre cartões.

Depois de analisar o HTML, o navegador cria o DOM, uma representação do documento em forma de objetos conectados.

JavaScript pode:

  1. selecionar um elemento;
  2. observar um evento;
  3. ler o estado atual;
  4. alterar propriedades;
  5. atualizar o que o usuário percebe.

Fluxo da interação

1. SELECIONAR
querySelector encontra botão e painel
        ↓
2. OUVIR
addEventListener observa o clique
        ↓
3. ALTERAR
hidden, aria-expanded e texto mudam
        ↓
4. EXIBIR
o navegador redesenha o resultado

O arquivo HTML no disco não é reescrito. O JavaScript altera o DOM carregado na memória.

Preparar o arquivo externo

Confirme nas três páginas:

<script src="js/script.js" defer></script>

Não use:

<button onclick="mostrarOrientacao()">Mostrar</button>

O evento será registrado no arquivo js/script.js.

No início de js/script.js, digite:

"use strict";

// Procura o botão pelo id único definido no HTML.
const botaoOrientacao = document.querySelector("#botao-orientacao");

// Procura o painel controlado pelo botão.
const painelOrientacao = document.querySelector("#painel-orientacao");

// O mesmo script é carregado nas três páginas.
// A interação só será configurada quando os dois elementos existirem.
if (botaoOrientacao && painelOrientacao) {
  // O evento de clique será registrado na próxima etapa.
}

Entendendo querySelector

document.querySelector("#botao-orientacao")
  • document: representa o documento carregado;
  • querySelector: procura o primeiro elemento correspondente;
  • #botao-orientacao: seletor CSS de ID;
  • o retorno será o elemento ou null.

Prática WP09

Preveja o valor de botaoOrientacao em index.html e detalhes.html. Explique por que a condição evita o erro relacionado a null.

Dentro do if, substitua o comentário pelo evento:

if (botaoOrientacao && painelOrientacao) {
  botaoOrientacao.addEventListener("click", () => {
    // Guarda o estado existente antes da mudança.
    // true significa que o painel estava oculto.
    const estavaOculto = painelOrientacao.hidden;

    // O operador ! inverte true e false.
    painelOrientacao.hidden = !estavaOculto;

    // Se estava oculto, agora foi expandido.
    // O atributo precisa receber texto: "true" ou "false".
    botaoOrientacao.setAttribute(
      "aria-expanded",
      String(estavaOculto)
    );

    // O texto sempre anuncia a próxima ação possível.
    botaoOrientacao.textContent = estavaOculto
      ? "Ocultar orientação"
      : "Mostrar orientação";
  });
}

botaoOrientacao.addEventListener("click", () => {})

  • aguarda o evento click;
  • executa a função quando o evento acontece;
  • funciona com mouse e com teclado em um

JavaScript do ano

// Procura o elemento marcado no rodapé.
const anoAtual = document.querySelector("[data-ano-atual]");

// Atualiza somente quando o elemento existe.
if (anoAtual) {
  anoAtual.textContent = new Date().getFullYear();
}

Entendendo cada parte

  • new Date(): cria um objeto que representa uma data;

  • textContent: substitui o conteúdo textual do span.

A data do dispositivo pode estar incorreta. Use essa técnica para conveniência visual, não para regras financeiras, jurídicas ou de segurança.

Sincronizar o computador

No terminal:

git switch main
git pull
git branch -d feature/site-inicial
git fetch --prune
git status

Entenda:

  • switch main: volta para o branch principal;
  • pull: recebe o merge;
  • branch -d: exclui o branch local com verificação;
  • fetch --prune: remove referências remotas obsoletas;
  • status: confirma o estado final.

Não substitua -d por -D automaticamente se houver recusa. Primeiro confirme que o trabalho foi integrado.
